## Security — process fixed, tokens NOT rotated

The operator explicitly declined token rotation and asked for the **process** to
be fixed so leaks stop recurring. Done:

- **`url.insteadOf` installed globally.** Any `https://github.com/...` URL is
  rewritten to SSH before git stores it, so a token pasted into a clone URL can
  never land in a `.git/config`. This closes the exact path that leaked the PAT
  into `~/NeuroOmni.Vag-Agenti/.git/config`.
- **`~/.git` deleted.** Home is no longer a git repository, so a stray
  `git add -A` there now fails instead of staging everything.

**What `~/.git` actually was**, since it was never diagnosed before: `git init`
run in home on 2026-06-06, then a mass `git add` on 2026-08-18 00:53 that wrote
**122,018 blobs / 2.8 GB** into the object store — all blobs, zero trees, zero
commits, which is the signature of `add` without `commit`. It never completed,
the index was cleared, and the blobs were orphaned. 5.3 GB reclaimed.

Its origin is now known: the Drive document on compiling the wiki into repos
advised *"Turn your Obsidian vault folder into its own git repository via Termux
(`git init`)"*. That was run against **home** instead of the vault.

**Nothing was ever committed, so nothing was ever pushed — that data never left
the device, and it is now deleted.**

Still open, operator's call, not done:

- `OPENAI_API_KEY`, `GROQ_API_KEY` in `~/.config/watch/.env`, and the GCP service
  account in `~/.credential-quarantine-2026-08-17/` are unrotated.
- **Pre-commit guard not installed.** Proposed: global `core.hooksPath` hook
